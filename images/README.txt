HASALMUN'27 — PHOTO SLOTS
=========================

The website looks for photos in this folder. If a file is missing, a
branded placeholder (committee emblem / member icon) is shown instead.
This means you can add photos one by one, at any time, without editing
any code: just drop the file in with the right name and refresh.

Tips
----
- JPG files also work: either rename your file to .png, or change the
  extension in the HTML (e.g. src="images/committee-icao.jpg").
- Recommended sizes: committee photos ~800x600 px, member photos
  ~600x480 px. Anything larger is fine — photos are cropped to fit.
- File names must match exactly (lowercase, with the hyphen).
